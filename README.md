# Менеджер контактов организаций

![Version](https://img.shields.io/badge/version-1.0-blue)
![Python](https://img.shields.io/badge/python-3.8%2B-green)
![Kivy](https://img.shields.io/badge/framework-Kivy-orange)

Профессиональное приложение для управления базой контактов, организаций и магазинов. Интерфейс выполнен в виде иерархической таблицы в стиле Excel, что позволяет удобно работать с большими объемами данных в формате B2B.

## 📋 Основные возможности

- **Иерархическая структура:** Ответственные лица → Организации → Магазины → Контакты.
- **Разделение контактов:** Отдельный учет ЛПР (Лиц, принимающих решения) и контактов для оплаты.
- **Неограниченное количество контактов:** Вы можете добавлять сколько угодно людей к каждому магазину.
- **Мгновенный поиск:** Поиск по ФИО, должностям, адресам, городам и телефонам по всей базе.
- **Копирование данных:** Двойной клик по любой ячейке копирует текст в буфер обмена (с визуальным подтверждением зеленой вспышкой).
- **Экспорт в Excel:** Выгрузка всей базы в формат `.xlsx` с сохранением табличной структуры и рамок. Файл автоматически сохраняется на Рабочий стол в папку **"Экспорт контактов"**.
- **Темная тема:** Современный дизайн с настраиваемой палитрой цветов.

## 🛠 Технологический стек

- **Язык:** Python 3.8+
- **UI Фреймворк:** Kivy 2.3+
- **База данных:** SQLite3 (локальный файл `contacts.db`)
- **Экспорт:** OpenPyXL

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Londimain/Organization-Contacts-Manager.git
   cd Organization-Contacts-Manager
   ```

2. **Создайте виртуальное окружение и активируйте его:**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install kivy openpyxl pyinstaller
   ```

4. **Запустите приложение:**
   ```bash
   python main.py
   ```

## 📦 Сборка в EXE (Windows)

Для компиляции проекта в один исполняемый файл используйте PyInstaller. Убедитесь, что папка `ico` с иконкой `manager.ico` находится в корне проекта.

```powershell
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue

pyinstaller --onefile --windowed --name OrganizationContacts --icon="ico/manager.ico" --add-data "ico;ico" --hidden-import win32timezone main.py
```
Готовый файл `OrganizationContacts.exe` появится в папке `dist`.

## 📂 Структура проекта

- `main.py` — точка входа в приложение.
- `app.py` — главный класс приложения и логика интерфейса.
- `database.py` — работа с SQLite базой данных.
- `export.py` — логика экспорта в Excel.
- `widgets.py` — кастомные виджеты (кнопки, строки таблицы).
- `popups.py` — всплывающие окна (формы, подтверждения).
- `constants.py` — палитра цветов и настройки дизайна.
- `about.py` — текст для окна "О программе".
- `ico/` — папка с иконками.
