# Менеджер контактов организаций

Профессиональный инструмент для управления базой данных контактов, организаций и торговых точек. Программа позволяет вести иерархическую базу, быстро искать информацию, работать в локальной сети и выгружать данные для работы в Excel.

## 📋 Основные возможности

* **Иерархическая структура**: Ответственные лица → Организации → Магазины → Контакты.
* **Разделение контактов**: Четкое разделение на ЛПР (Лица, принимающие решения) и Оплату.
* **Смена типа контакта**: Перевод контакта из ЛПР в Оплату (и обратно) без удаления.
* **Сквозной поиск**: Мгновенный поиск по всей базе (ФИО, города, адреса, телефоны, должности, номера договоров) с подсветкой совпадений.
* **Множественное выделение**: Выделение нескольких строк с помощью клавиш `Shift` (сплошной диапазон) или `Ctrl` (выборочно).
* **Умное копирование**: Копирование выделенных строк (`Ctrl+C`) с сохранением структуры колонок для идеальной вставки в Excel. Копирование отдельной ячейки доступно по двойному клику или правой кнопкой мыши.
* **Работа в сети и автообновление**: Программа автоматически подгружает изменения, сделанные другими пользователями (каждые 2 секунды), не сбрасывая ваше текущее выделение и раскрытые ветки.
* **Экспорт в Excel**: Автоматическое сохранение всей базы в файл на Рабочем столе (в папке «Экспорт контактов»).
* **Корзина**: Безопасное удаление данных с возможностью выборочного восстановления.
* **Валидация**: Проверка корректности ввода телефонов и дат.

## ⌨️ Горячие клавиши

* `Ctrl + F` — переход к полю поиска.
* `Ctrl + C` — копирование выделенных строк в буфер обмена.
* `Enter` — редактирование выбранной строки (вне форм ввода).
* `Insert` — добавление нового элемента.
* `Delete` — удаление выбранного элемента.
* `Enter` (в формах) — сохранение введенных данных.

## 🚀 Установка и запуск (для разработчиков)

1. Убедитесь, что у вас установлен **Python 3.8** или выше.
2. Клонируйте репозиторий и перейдите в папку с проектом.
3. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   ```
4. Установите необходимые зависимости:
   ```bash
   pip install kivy openpyxl
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```

## 🌐 Настройка работы в сети (Общая база данных)

⚠️ **Важно:** Не используйте Google Drive или Яндекс.Диск для хранения файла базы данных (`contacts.db`). Облачные сервисы блокируют файл во время синхронизации, что приводит к ошибкам и повреждению базы данных. 

Для совместной работы используйте **локальную сеть (SMB)**:
1. На главном компьютере создайте папку (например, `C:\ОбщаяБаза`) и откройте к ней общий доступ по локальной сети с правами на чтение и запись.
2. Поместите в эту папку файл `contacts.db`.
3. На каждом компьютере откройте файл настроек: `Win + R` → введите `%APPDATA%\ManagerContacts` → откройте `settings.json`.
4. Укажите путь к сетевой базе в параметре `db_path` (используйте двойные слеши):
   ```json
   "db_path": "\\\\192.168.1.10\\ОбщаяБаза\\contacts.db"
   ```
5. Перезапустите программу. Теперь все изменения будут синхронизироваться между пользователями в реальном времени.

## 📦 Сборка в один EXE-файл (Windows)

Для сборки автономного исполняемого файла используется **PyInstaller**.

Установите PyInstaller:
```bash
pip install pyinstaller
```

Выполните команду в терминале (находясь в корневой папке проекта):
```bash
pyinstaller --onefile --windowed --clean --name ManagerContacts --icon="ico/manager.ico" --add-data "ico;ico" main.py
```
Готовый файл `ManagerContacts.exe` появится в папке `dist`.

## 📁 Структура проекта

* `main.py` — точка входа в приложение.
* `app.py` — основной класс приложения, интерфейс и логика взаимодействия.
* `database.py` — работа с базой данных SQLite3 (открытие/закрытие соединения при каждом запросе для стабильной работы в сети).
* `widgets.py` — кастомные виджеты (кнопки, строки таблицы).
* `popups.py` — всплывающие окна (формы, корзина, подтверждения).
* `export.py` — логика экспорта в Excel.
* `settings.py` — управление настройками (включая путь к сетевой базе).
* `logger.py` — настройка логирования.
* `about.py` — текст окна «О программе».
* `constants.py` — цветовая палитра и константы интерфейса.

## 💾 Расположение данных

* **База данных** (`contacts.db`) по умолчанию создается в одной папке с исполняемым файлом (или `main.py`). Путь можно изменить в `settings.json`.
* **Настройки** (размер окна, путь к БД) и **логи** работы сохраняются в системной папке пользователя: 
  `%APPDATA%\ManagerContacts\` (например, `C:\Users\Имя\AppData\Roaming\ManagerContacts`).
