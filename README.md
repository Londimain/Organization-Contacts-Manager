# 📇 Менеджер контактов организаций

Профессиональный инструмент для ведения базы данных контактов, организаций и торговых точек с поддержкой сетевого режима, автоматической синхронизации и встроенной системы обновлений.

## 📋 О программе

Программа позволяет вести иерархическую базу данных:
**Ответственные лица ➔ Организации ➔ Магазины ➔ Контакты (ЛПР и Оплата).**

Интерфейс выполнен в современном темном стиле с цветовым кодированием уровней для быстрой навигации. Программа отлично подходит как для локального использования, так и для работы в сети несколькими сотрудниками одновременно.

## 🚀 Основные возможности

### Управление данными
* **Иерархическое дерево:** Удобное управление структурой с возможностью сворачивания/разворачивания веток.
* **Умный импорт из Excel:** Программа распознает иерархию по цвету заливки ячеек (желтый — отв. лица, оранжевый — организации, без цвета — магазины).
* **Экспорт в Excel:** Выгрузка всей базы в файл `.xlsx` с автоподбором ширины столбцов и рамками.
* **Корзина:** Мягкое удаление записей с возможностью восстановления.
* **Поиск и копирование:** Сквозной поиск по всей базе и удобное копирование данных в буфер обмена с визуальным откликом.

### Сетевая работа и синхронизация
* **Гибкое подключение:** Поддержка локальной и сетевой базы данных (SQLite). Путь к базе настраивается прямо в меню «Настройки».
* **Автосинхронизация:** Если коллега на другом ПК изменит сетевую базу, программа автоматически подтянет изменения (сохраняя открытые папки и выделение).
* **Индикатор базы:** В нижней панели всегда отображается текущий режим работы (Локальная / Сетевая).
* **Без зависаний:** Все сетевые операции и загрузка данных выполняются в фоновых потоках.

### Безопасность и система
* **Защита паролем:** При запуске программа запрашивает пароль для предотвращения несанкционированного доступа. (Текущий пароль: `soft`).
* **Защита от запуска второй копии:** Предотвращает случайное открытие программы дважды.
* **Встроенная система обновлений:** Программа сама проверяет наличие новых версий на сетевом диске и предлагает обновиться.

## 📦 Сборка и публикация

### 1. Сборка EXE файла
Для сборки основного исполняемого файла используется PyInstaller:
```bash
pyinstaller --onefile --windowed --clean --name ManagerContacts --icon="ico/manager.ico" --add-data "ico;ico" --version-file=version_info.txt --hidden-import=win32timezone main.py
```

### 2. Сборка установщика
Сборка инсталлятора осуществляется через **Inno Setup** с использованием скрипта `manager_installer.iss`. 
Результат сборки (файл `ManagerContacts_Setup_vX.X.X.exe`) появится в папке `installer_output`.

### 3. Публикация обновлений
Для выпуска новой версии используется утилита `publisher.py` (собирается в EXE через PyInstaller). Она автоматически:
1. Обновляет версию во всех файлах проекта (`version.py`, `.iss`, `.txt`, `.json`).
2. Копирует новый установщик в сетевую папку.
3. Удаляет старые версии установщиков.
4. Генерирует новый `version.json` для автообновления у клиентов.

* `updater.py` — логика проверки и установки обновлений.
* `popups.py` — диалоговые окна (настройки, формы, корзина, окно входа).
* `version.py` — центральный файл с метаданными и версией.
* `publisher.py` — утилита для подготовки релизов.
